🏦 الدفع بالتحويل البنكي

قبل التحويل، تواصل مع إدارة المتجر لتأكيد المبلغ وتفاصيل الحساب البنكي. لم تُضف بيانات بنك بعد، لذلك لن نعرض أرقاماً غير صحيحة.

بعد التحويل، أرسل صورة الإيصال بنفسك في محادثة تلغرام. رفع الإيصال تلقائياً يحتاج خادماً آمناً غير موجود في GitHub Pages.

لا ترفع إيصالاً يحتوي على معلومات غير ضرورية، ولا تشارك رمز التحقق أو كلمة مرور البنك.
